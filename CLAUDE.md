# Project Policies

## Branch & merge policy

- When a change is complete (implemented, verified/builds cleanly, and committed), **merge it to `main` and push `main`** — do not leave finished work sitting only on a working branch.
- Work may be developed on a working branch, but every finished change ends with `main` updated.
- Never merge broken or unverified work to `main`; verify the build (and game boots, once it exists) first.

## Project

Fan-made 3D web game (Three.js + TypeScript + Vite) inspired by *The Mandalorian*.
See `docs/PLAN.md` for the full design and build plan.
