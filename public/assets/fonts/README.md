| `playfair-display-italic-600.woff2` | Playfair Display, italic 600 | SIL Open Font Licence 1.1 |
| `barlow-condensed-500/600/700.woff2` | Barlow Condensed | SIL Open Font Licence 1.1 |
| `alfa-slab-one-400.woff2` | Alfa Slab One | SIL Open Font Licence 1.1 |
| `ibm-plex-mono-600.woff2` | IBM Plex Mono, 600 | SIL Open Font Licence 1.1 |
| `special-elite-400.woff2` | Special Elite | Apache Licence 2.0 |
